# PBZ 战斗助手 0.12.0 · 使用说明

## 这一版修了什么

上一版（0.11.0）实机 diag 暴露了两个硬伤：

1. **敌人一个都认不出来**：`faction_components=12`（组件扫到了），但 `ComponentTag()` 读 `component.Faction`
   在实机返回 nil → `faction_seen=0`、`enemy_count=0` → 永远 `search_target`，**一刀不出**。
   0.12.0 改成用**组件 owner 的类名**判断敌人（实机已证 `BP_Monster_HuaQianXIiao_C`），Faction 标签只做兜底。
2. **喝药误判 + 普攻假装成功**：`heals=15` 但血量一直 892.5/892.5，说明药根本没吃到；
   普攻计数只看注入不看出血。0.12.0 两者都改成**看结果**：
   - 喝药：注入后 2.5 s 内血量涨幅不够 → 记 `heal_fail`，自动换到快捷道具槽（`heal_alt`）再试一次；不会误判停手。
   - 普攻：下一刀前对比目标血量 → 记 `attack_ok` / `attack_no_damage`。

另外扫描从「每 0.22 s 全量 `FindAllOf('Actor')`（实测 57–97 ms 一次）」改成
「有目标 2.5 s 一次、无目标 0.8 s 一次，每 tick 只刷新已知敌人」，卡顿会明显下降。

## 用法

1. 先开游戏，再开 `PBZ战斗助手-0.12.0.exe`。
2. 点「选择游戏」指向 `E:\Steam\steamapps\common\PBZ\platform\steam\PBZ.exe`，等状态变「已连接」。
3. Mod 本版**已经直接写进游戏目录**（`ue4ss\Mods\PBZSmartCombat`，`VERSION='0.12.0'`），**重启游戏**才会加载新版。
4. 开局后按 **F8** 开始 / **F10** 停止。关掉助手窗口会自动停手（lease 4 s 到期）。

## 打完一局请回传这两个文件

`E:\Steam\steamapps\common\PBZ\platform\steam\ue4ss\Mods\PBZSmartCombat\`

- `diag.txt` —— 重点看 `enemy_classes_seen`（这关真实敌人类名）、`enemy_list`、`attack_ok` / `attack_no_damage`、`heal_ok` / `heal_fail`
- `status-a.ini` —— 重点看 `enemy_count`、`target`、`attacks`、`blocks`

这两份能直接告出「不打」是三步里的哪一步：
`找出敌人 → 进攻击距离 → 注入攻击动作`。

## 关于黑屏

排查结论：助手本身不碰显示模式（`windows_io.py` 只有 DPI 感知、热键、SendInput）。
真正的问题更可能在机器侧 —— 系统日志显示 11/2 **13:06:10 / 13:36:09 / 13:49:06 三次「上一次关机是意外的」**，
且没有蓝屏 dump、没有 WHEA 17/18/19、没有显卡 TDR，属于**整机硬挂**（断电/死机后强制关机级别的故障）。
建议：先把内存 XMP 关掉、查一下电源和显卡供电、看散热；游戏改无边框窗口跑一局观察。
